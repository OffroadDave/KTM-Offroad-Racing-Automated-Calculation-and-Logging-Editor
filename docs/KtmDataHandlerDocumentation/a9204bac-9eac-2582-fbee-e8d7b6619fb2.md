# ITimeseriesIsStateSignal Method   
  
---  
  
Check if a timeseries is a state signal by comparing the number of different states (smaller than 50). This is to avoid filtering "normal" state signal, but also signals with a higher number of states (e.g. a corner number channel) If the method returns true, a downsampling filter in case of resampling is not applied.
