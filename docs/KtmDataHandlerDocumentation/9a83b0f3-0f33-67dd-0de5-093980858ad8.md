# TyreInformationSnapshotAreEqual Method   
  
---  
  
Checks that snapshots records are equal, meaning that tyre record lists in both snapshots have exactly the same elements. Record equality is based on TyreInformationRecord.Equals method. 

This equality ignores timestamps, machine and user names.
