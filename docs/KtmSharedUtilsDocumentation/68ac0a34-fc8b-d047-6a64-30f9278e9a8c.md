# T1DGetIndex Method   
  
---  
  
Get the "INDEX" of an interpolation. The INDEX is defines as: 

  * **1** \- When the interpolating value is less than the first element in the breakpoint array
  * **Dimensione of the breakpoint array** \- When the interpolating value is greater than the last element in the breakpoint array
  * **The one-based index of the first breakpoint value greater than the interpolating value** \- When the interpolating value is between the first and last breapoint elements
