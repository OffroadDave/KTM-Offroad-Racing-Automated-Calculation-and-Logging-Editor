# UtilsCompare Method   
  
---  
  
Compare by property value two objects. The comparison is Json-based, so the public properties/fields only will be considered. In order to include the private/protected items, add the attribute "[JsonProperty(DefaultValueHandling = DefaultValueHandling.Include)]" just above each property It differs from KtmSharedUtils.ObjectUtils.ReferenceEqualityComparer because by using this last you compare the references of two objects and not their property values.
