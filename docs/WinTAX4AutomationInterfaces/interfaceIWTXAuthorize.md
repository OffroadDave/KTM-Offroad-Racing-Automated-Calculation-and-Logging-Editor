## Detailed Description

The IWTXAuthorize interface is directly derived from [ITelAuthorize](interfaceITelAuthorize.md). Refer to the [ITelAuthorize](interfaceITelAuthorize.md) interface documentation for a list of methods / properties. 

**Note:**
     You must use this interface instead of [ITelAuthorize](interfaceITelAuthorize.md) to authenticate the [IApplication](interfaceIApplication.md) interface if it is used by 64-bit applications.
