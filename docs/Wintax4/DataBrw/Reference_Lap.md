## Reference Lap

This feature is available in some licenses only.

The Reference Lap identifies a lap and it is used to compare the data currently loaded. After the reference lap has been selected, it will always show until the user deletes it. All the analysis carried out with the enabled Reference Lap, will show this type of lap as the first lap of any comparison. The reference lap is used to compare more laps with the same reference lap without loading it each time. It is for instance useful when the user wishes to compare the various laps of a race with the fastest lap.

The Reference Lap can identify a single lap but can also identify a lap append; it is possible to select more laps that when set as a reference, become linked one to the other to form a single reference lap.

The Reference Lap can be loaded as follows:

  * from WinTAX4 through the Data/Select Reference Lap menu; this command opens the Data Browser in reduced mode where the Reference Lap can be selected.

  * From Data Browser through the File/Set Reference Lap command. The command sets the selected laps as reference.

  * From Data Browser one or more laps can be selected and Set Reference Lap command is chosen using the menu displayed with the right button.




The Reference Lap can be removed as follows:

  * From Data Browser through the File/Remove Reference Lap command.

  * From Data Browser using the right button on the lap list and choosing "Remove Reference Lap".




The Reference Lap is displayed as first line of Data Header both of the Data Browser and of WinTAX4 as shown in the figure where also the Set and Remove commands are highlighted; the reference slot is indicated by the letter R.

The next 10 comparisons will be displayed as usual with number from 1 to 10.

Note: The Lap+ and Lap- command do not affect the Reference Lap so not to move the reference. In this way the laps can be quickly compared to the Reference Lap without loading the comparison lap each time.

In the configuration window of the [Graph](../AnalysisWnds/Wnds/GRA/GRAWndOverview.md), inside the [Comparison](../AnalysisWnds/Wnds/GRA/GRAWndSetup.md#Comparison) tab, the first slot is dedicated to the Reference Lap.

In case Auto or Difference option are active, the difference is automatically calculated by default between the Reference Lap and the other laps.
