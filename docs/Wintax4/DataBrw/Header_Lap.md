## Lap Info Bar

The Lap Info bar is placed below the Session and Lap lists and displays the information about the selected laps.

If no lap is loaded, the writing No Data appears on light blue background. Loading a lap, the information about the lap are displayed, as configured in the Session and Lap parts of the [Header Configurations](Options_Configuration.md) page.

If an appended lap is loaded, a single line is displayed where the information varying from lap to lap (for instance Abs) are presented in sequence, separated by a comma if they are consecutive, or if not as a range separated by colon.
