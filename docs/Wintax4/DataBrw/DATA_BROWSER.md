## Data Browser Overview

The data browser is a tool which allows to manage WinTAX4 data files recorded during acquisition sessions. As the name implies, the data browser is mainly used to view the contents of data archives and to select single laps or groups of laps for display and analysis. Other functions are related to the management of the files in the archive and include editing lap header data, and logging session records.

In order to understand the functions of the data browser it is useful to understand the underlying structure of the [data archive](DataArchives_Full.md) and its constituent files.

The interface of the Data Browser is formed by the following parts:

  * [Sessions List](Session_Laps.md) List of the sessions available in the WinTAX4/Data directory

  * [Lap List](Session_Laps.md) List of the Runs and of the Laps available in a session

  * [Lap list Icons](Session_Laps.md#Icons_in_the_lap_list) \- Explains in more depth the icons used in the lap list

  * [Select Archive Combo](Menu.md#SelectArchive) Selection of the basic directory to be scanned to view the possible sessions.

  * [Menu (Files, Edit, View, Tools)](Menu.md) Commands for all operations to be carried out on the Data Browser

  * [Toolbar](Menu.md) Commands for all operations to be carried out on the Data Browser

  * [Header Laps](Header_Lap.md) Contains all information about the loaded lap

  * Status Bar  Contains some information about the status of the window. In case of long operations, there is a progress bar displaying the advancing of the operations.
