## TelDataX

TelDataX is a COM component which allows reading WinTAX4 data archives (ZTX and DTX) from your own custom built applications. If WinTAX4 is installed also the math channel libraries can be used.

The [TelDataX Programmer's Reference](TelDataX4Reference.chm::/index.md) can be found in the WinTAX4\docs directory.

Example code and applications are found in the WinTAX4\samples directory.

TelDataX is an optional component and is supplied as a separate licence from WinTAX4.
