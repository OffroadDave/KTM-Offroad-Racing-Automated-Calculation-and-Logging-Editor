##  TelDataZTX

TelDataZTX is a WIN32 DLL which allows to write WinTAX4 data archives (ZTX) from your own custom built applications.

The TelDataZTX Programmer's Reference can be found in the WinTAX4\docs directory

Example code and applications are found in the WinTAX4\samples directory

TelDataZTX is an optional component and is supplied as a separate licence from WinTAX4.
