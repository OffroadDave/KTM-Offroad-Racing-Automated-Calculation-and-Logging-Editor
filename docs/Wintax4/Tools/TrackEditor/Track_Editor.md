#### Track Editor Overview

The Track Editor is the environment dedicated to generate the Track (circuit trajectory) and the Track Sections (Map) linked to a Track. Note that in WinTAX4 the expression 'Track' and 'Track Sections' corresponds to 'Circuit' and 'Map' respectively. In order to start using the Track Editor, go to menu: Tools/Track Editor or use the ALT + T shortcut. The Track Editor needs at least one lap loaded in WinTAX4 to work properly.
