### Elements of the window

The Track Editor dialog is composed by the following logical areas:

  * **Track Sections Table** : tabular editor of sectors distance (length and type of the sector).

  * **Preview and Orientation Area** : graphical preview of circuit and sections with the ability to tune sectors positioning and to rotate the track.




#### Track Sections Table

The Track Sections table allows to manually customize the number, type and length of sections the track is divided in. See [Generate Track Sections](GenerateTrackSections.md) for further details.

####  Preview Area

In the preview area there may be one or two distinct zones, chosen by the combo preview, circuit and graphs. The first area shows the circuit, the second area displays a graphical window. Through menu commands and with the mouse, you can change the sections of the circuit.

In the preview area the user can choose to display circuit, graph or both. The combo “Preview” allows switching between these three options. The upper area shows the circuit and the lower area is dedicate to display the graphical window.

It is possible to define and tune sectors working on the graphs:

  * within Circuit you can modify the sector and finish line position. Move the mouse near the sections separating lines: the section will become active and you will be able to move it on the track.

  * within Graph you can define sectors: use “Manual Section Definition” button to activate the edit mode.




In the top right of the Circuit area there is a compass rose; clicking on it, the track is automatically turned with North towards the top of the screen. The track can rotate pressing the CTRL key and using mouse wheel.
