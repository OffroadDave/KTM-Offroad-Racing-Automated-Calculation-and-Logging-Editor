### Export Snapshot

The dialog opens by selecting Setup/User/Export User Snapshot. This export function can export the complete set (events, VCH libraries, layouts, windows, data) of user settings.

In the dialog you can choose the output file and which elements to export. The extension of a snapshot export file is .zss. A .zss file is an archive which contains Libraries, System data, Circuits, User Information and Data Loaded.

In the "Export system snapshot" dialog it is possible to choose which items to export from the check list.

#### Libraries

  * **VCHs:** Export of all virtual channels libraries within “WinTAX4\Libraries” folder (local and global). 
  * **Conditions:** Export of all Conditions libraries within “WinTAX4\Libraries” folder.
  * **Events:** Export of all Events libraries within “WinTAX4\Libraries” folder.
  * **Lookups:** Export of all lookup tables within “WinTAX4\Libraries” folder either.
  * **Parameters** : Export of “Parameters” settings and “Local Groups” defined in WinTAX4 (folder “WinTAX\System”



#### **S ystem**

  * General Setup: Export of “General Setup “settings and current loaded track ( stored within “WinTAX\System” folder
  * Directories: Export of directories setup from General Setup page (“WinTAX\System” folder)
  * Setup Acquisition: Export of all acquisition settings: vehicles setup, session setup (“WinTAX\System” folder)
  * Rx Tasks: Export of Rx Tasks settings from Acquisition Manager (“WinTAX\System” folder)
  * Accelerators: Export of WinTAX4 Accelerators setting (“WinTAX\System” folder)
  * Global VCH Settings: Export of “global” VCHs libraries (“WinTAX\System” folder)



#### **Circuits**

  * To export all circuits within “WinTAX4\Circuits” folder



#### **Users**

  * **Layouts : to export all layout, windows and layout bar status (“WinTAX4\CurrentUser” folder**
  * **Condition Settings : to export status of loaded Condition libraries (“WinTAX4\CurrentUser” folder)**
  * **Data Header : to export the configuration of the data header.**
  * **Events Settings : to export status of loaded Event libraries (“WinTAX4\CurrentUser” folder)**
  * **Setup Users : to export the following settings ( “WinTAX4\CurrentUser” folder):**
    * **Show/Hide Events**

    * **Dataset Panel status**

    * **Pop-Up Track status**

    * **Transparent Pop-Up Track property**

    * **Set Datum status inside Legend window**

  * **T****oolbars : To export toolbar status.**
  * **Local VCH Settings : ****to export "local" level of VCHs libraries ("WinTAX4\CurrentUser")**



#### **Data**

  * **To export currently loaded data**




**The operation can take several minutes. When the export is successful, the following message appears:**

****

**_Exporting circuits_**** _: as described above, the “Circuits” option allows you to export all circuits within \WinTAX4\Circuits\ folder.__The circuit currently opened in WinTAX4 and the Pop-Up track status are not included in the export._**

**_To do that:_**

  * **_Select “Circuits” + “General Setup”_ _à_ _the Circuit currently opened in WinTAX4 will be included within the export file_**

  * **_Select “Circuits” + “General Setup” + “Setup User”_ _à_ _the Circuit currently opened in WinTAX4 will be included within the export file; The status of "Pop-Up track" and the "Transparent popup track" statuses will be included within the export file._**
