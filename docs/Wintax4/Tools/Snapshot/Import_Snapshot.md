### Import Snapshot

The command Setup/User/Import User Snapshot opens a window dialog for choosing a .zss file to import. After choosing the desired .zss file, WinTAX4 extracts and restores directories and files from the archive to the program directories structure.

If there are existing files in the folder structure, WinTAX4 alerts the user with the following message.

You can choose to maintain or replace the old files with the same name.
