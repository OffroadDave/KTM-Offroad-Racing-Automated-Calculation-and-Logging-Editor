## Wizard Environment

The Wizard environment of the Acquisition Manager allows configuring and efficiently enabling the various acquisition processes through a guided sequence of operations that might result complex to an unskilled user if no guideline is provided.

The commands to use Wizard are in the Acquisition menu.

The Acquisition Manager offers various Wizards depending on the WinTAX4 licence.

  * [TCP Download Wizard](AcqMng_TCPAcqWizard.md "TCP Acquisition Wizard")

  * [Real Time Download Wizard](AcqMng_DSTAcqWizard.md "DST Acquisition Wizard")

  * [Marvel Download Wizard](Marvel_Wizard.md)

  * [USB/FlashCard Download Wizard](Flash_Card_Wizatrd.md)

  * [DVR Download Wizard](AcqManager_DVRStartupWizard.md)

  * [CAN Download Wizard](AcqMng_CANAcqWizard.md)

  * [Session Startup Wizard](AcqMng_SessionStartupWizard.md "Session Startup Wizard")
