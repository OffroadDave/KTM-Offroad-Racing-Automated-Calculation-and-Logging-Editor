## DVR Acquisition

Process of data transfer from a Data video Recorder. The data can be manually or automatically downloaded through, respectively, the Manual Download function (DLM) and the Auto Download (ADL) function.

##### DVR toolbar: list of the available commands:

Activate DVR: Starts/Stops the acquisition process. 

| STATUS | DESCRIPTION |
| --- | --- |
|  | Process enabled and connection with the device displayed in the dropdown combo box. |
|  | Process enabled and connection failed |
|  | Process not active |
  
### DVR Commands:

| ICON | COMMANDS | DESCRIPTION |
| --- | --- | --- |
|  | Activate DVR | Starts/Stops the acquisition process. |
|  | Download data from data logger DVR | Shows the "Download data" window, that allows the selection of laps to be downloaded. |
|  | Auto Download DVR | Enables / Disables an Auto Download session |
|  | Download latest data DVR | Downloads all laps from the selected device once. |
|  | Log Messages DVR | Shows/Hides the log window |
|  | Clear data DVR | Command to delete all data from the Logger. |
  
### Configuration of the acquisition process

Auto Download: Enabling/Disabling an Auto Download (ADL) session.

Reset auto download counter: reset the ABS counter of downloaded laps.

Manual Download Options:

Update auto download counter after Manual download: when this option is enabled the auto download counter will be automatically updated. This will force the following Auto Download session to restart the download from the last ABS counter that was downloaded in manual download.

FlashCards: list of USB/FlashCard paths

Options:

  * Add: Open the browse selection to add a new path.

  * Browse: Open the browse selection to change current path.

  * Remove: Remove the selected path.

  * Clear all: Remove all paths.




#### Lap information

The list of information displayed in the header of the download window can be configured in the "Lap Information" page.
