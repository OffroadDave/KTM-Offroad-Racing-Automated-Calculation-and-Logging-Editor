## Wireless Distribution System (WDS)

It is a acquisition process that permits to connect WinTAX4 to a data multicast generated by MDS (Marelli Data Server).

All commands and their procedures to acquire Real Time data are described here.

##### WDS bar: list of the commands available

Activate WDS enabling/disabling of the acquisition process

| Status | Description |
| --- | --- |
|  | Process enabled and connection with the device displayed in the combo |
|  | Process enabled and connection failed |
|  | Process not active |
  
| ICON | Commands | Description |
| --- | --- | --- |
|  | Activate WDS | Start/Stop of the acquisition process. |
|  | Log Messages WDS | Shows/Hides the Log window |
  
###  Configuration of the acquisition process

Logging Table

  * Name: This file contains the logging table

  * System Setup: This file contains the channels setup




Data Acquisition

  * Don't save Data: If this flag is On, WDS process will not save dstData.ztx file

  * Auto Limit (sec): Limit the length of the lap.




Note: After 10 hours of consecutive acquisition, real time windows will be reset simulating a start over.
