## Toolbar Graph

The Toolbar Graph is a predefined toolbar that can be configured according to the selected window. Buttons cannot be manually added or removed. To see how the toolbar appears for each window, go to the help of the commands for each [analysis window](../AnalysisWnds/AnalysisWndsOverview.md).

The display of the Graph Toolbar can be enable/disable through the View/Toolbars/Graph Toolbar command of the main menu or by clicking with the right button on the area of the toolbars.
