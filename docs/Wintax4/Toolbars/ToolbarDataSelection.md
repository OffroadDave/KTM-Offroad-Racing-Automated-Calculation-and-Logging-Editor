## Data Selection Bar

The toolbar is divided into two parts showing information about runs and laps of the current session. It is predefined and cannot be configured. The Layout Toolbar visualization can be enabled/disabled through the View/Toolbars/Data Selection bar command of the main menu or by right clicking the button on the area of the toolbar. It was introduced to simplify the loading of data and can be seen as a compact representation of the Working DataSet. It is empty before the first loading of a DataSet.

The toolbar has a series of tabs on the left representing the loaded sessions. Various sections correspond to each tab where the laps of the run are displayed through the marker, if available, or the number of the lap.

Clicking one of the tabs, displays the corresponding Track Run laps.

One or more tabs or one or more sections of a tab can be selected using the CTRL key. The selected session border becomes green with the exception of those corresponding to the loaded laps that become red.

By double clicking on one of the sections selected or using the "Load Data into Working DataSet" command, the laps selected in the Working Dataset are loaded. This command is available in the pop-up menu and can be opened with the right button of the mouse on the lap area of the toolbar. The "Clear all Selections" command removes the selections from it.

By double clicking on a Run, the whole Run is loaded.

When the space required by the run area exceeds a limit, new navigation buttons are added.

A Load operation made on the Data Selection bar means actually loading data from the archive (from the local disk or from the network), it is not the same as the operations made on Interactive Data Header where data is already in memory.
