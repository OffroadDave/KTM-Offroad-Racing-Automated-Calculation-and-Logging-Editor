## Freehand Drawing Toolbar

The Freehand Drawing Toolbar is a predefined toolbar that cannot be configured. 

The Free hand Drawing includes a list of commands that are used to draw or write texts on the windows. The objects that are drawn on the windows are not saved in configuration and are only visible until the windows are closed. The same thing happens in a layout change. Once the objects are designed, they cannot be modified later. If the window size changes, the graphic objects will not maintain the position in the window but the dimension will change accordingly on each windows resize change.

The same commands are also available in the windows where the freehand drawing is enabled. The windows where the freehand drawing is enabled are the following (with their respective windows in Real-Time): [Graph](../AnalysisWnds/Wnds/GRA/GRAWndOverview.md), [XY](../AnalysisWnds/Wnds/XY/XYWndOverview.md), [XYZ](../AnalysisWnds/Wnds/XYZ/XYZWndOverview.md), [XYZ (3D)](../AnalysisWnds/Wnds/XYZ/XYZWndOverview.md), [Histogram](../AnalysisWnds/Wnds/IST/ISTWndOverview.md), [Track](../AnalysisWnds/Wnds/CRV/CRVWndOverview.md), [G-G Diagram](../AnalysisWnds/Wnds/GG/GGFeatures.md), [Trend](../AnalysisWnds/Wnds/TRE/TREWndOverview.md), [FFT Analysis](../AnalysisWnds/Wnds/FFT/FFTWndOverview.md). On all other windows that are not in the list, the toolbar is disabled. 

On Real-Time windows the Freehand Drawing is disabled during acquisition.

The Freehand Drawing commands are also shown in the Option menu or Popup menu in each of the above window.

Enable Freehand Drawing: The command is used to display or hide all items drawn. The command is global and affects all windows.

Draw Rectangle: This command is used to draw a rectangle with the wanted size. The thickness of the line is fixed and cannot be changed while the color can be changed with the Select Color command. In the case of scaling, the rectangle is consequently resized and keeps the proportions of the window.

Draw Arrow: This command is used to draw an arrow. The tip of the arrow is drawn at the point where the left mouse button is clicked. The thickness of the arrow is fixed and cannot be changed while the color can be changed with the Select Color command.

Brush: The paintbrush allows to trace freehand drawings. The thickness of the line is fixed and cannot be changed while the color can be changed with the Select Color command.

Draw Line: This command is used to draw a line. The thickness of the line is fixed and cannot be changed while the color can be changed with the Select Color command.

Insert Text: This command is used to write a text in a rectangle. The text uses the font Tahoma. The font size is not configurable and depends on the size of the rectangle. To accept the text, press Enter; when the text is confirmed is not possible to change it.

Select Color: The command allows to select the color with which the graphic objects and the text are drawn. The selected color is the same for all objects and is the same for all windows.

Clear All: The command deletes all the graphic objects in all the windows.

Clear Window: The command deletes all the graphic objects in the selected window.

Undo: This command deletes the last object drawn in the selected window.

Note: The second selection of any command before start the operation, allows to cancel the procedure.
