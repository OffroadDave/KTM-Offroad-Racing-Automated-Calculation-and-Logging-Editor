## Toolbar Real-Time

The Real-Time Toolbar is predefined so cannot be configured. Buttons cannot be manually added or removed.

The Graph Toolbar visualization can be enabled/disabled through the View/Real-Time Toolbar command of the main menu or with the shortcut CTRL+F9.

This window is used to give a quick access to the Real-Time acquisition functions. Double click on a device enables/disables the Real-Time acquisition process. Depending on the status of the process, icon can be colored as listed in the table.

| STATUS | DESCRIPTION |
| --- | --- |
| Green | Process activated and connection with the device visible in the combo |
| Red | Process activated and connection failed |
| Cyan | Process not activated |
  
To more details about the commands, please refer to [Real-Time](../Acquisition_Manager/DST/AcqMng_DST.md) section in Acquisition Manager.
