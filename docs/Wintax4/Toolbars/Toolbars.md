## Toolbars Overview

WinTAX4 has some default toolbars that are displayed or that can be displayed when the program is launched for the first time. The "Main" toolbar can be modified: so buttons can be added or removed; all other default toolbars cannot be modified. it is anyhow not possible to create new editable toolbars.

To view the toolbars, use the main menu [View/Toolbars](../Menu/View.md) and select or deselect the requested toolbars. The same operation can be carried out by clicking with the right button on the toolbars area.

Each toolbar can be kept floating or docked to the main window; some toolbar can be docked on each of the four sides of the window, some others can be docked only on top or on the bottom of the window. To dock a toolbar, drag it on the area of the window where you wish to dock it or double click on the "Title Bar". In this latter case the toolbar will be placed on the last area where it was docked. Vice versa to make a docked toolbar floating, double click on the external border of the toolbar or drag it with the mouse outside the dock area.

The configurable toolbars have a downwards arrow on their right. This arrow corresponds to a button that opens a menu through which some predefined commands can be added or removed from the toolbar.

Some commands are grouped based on their scope or based on the frequency of usage and they can be found in the Standard, Layout and Graph groups. Using the Configure menu (that has the same function as the command of the [Setup/Toolbars](../Menu/Setup.md) main menu) the configuration window of the [toolbars can be opened,](../WTXSetup/WndSetupToolbars/WTXSetupToolbars.md) through this window all commands on WinTAX4 can be added or removed.

The Default menu is available only in the predefined configurable toolbars of WinTAX4 (Main and Layout) and it allows adding or removing predefined commands or, through the "Reset" command, to restore the default situation of that toolbar.

The main menu [View/Toolbars](../Menu/View.md) has a "Reset Toolbars" command that restores positions and commands to WinTAX4 default configuration. All possible toolbars created subsequently are then removed. The command will execute only after user confirmation.

The default toolbars available in WinTAX4 are as follows

  * [Real time Toolbar](ToolbarDST.md)

  * [Data Header](ToolbarDataHeader.md)

  * [Graph Toolbar](ToolbarGraph.md)

  * [Data Selection Bar](ToolbarDataSelection.md)

  * [Main](ToolbarMain.md)

  * [Layout](ToolbarLayout.md)

  * [Freehand Drawing](ToolbarFreeHand.md)

  * [Track Sections Editor](ToolbarTrackSectionEditor.md)
