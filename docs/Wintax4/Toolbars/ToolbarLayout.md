## Toolbar Layout

This is a predefined toolbar and can also be configured. It offers a quick access to the management of a Layout. Displaying of the Layout Toolbar can be enabled/disabled through the View/Toolbars/Layout command of the main menu or with the right button on the area of the toolbars.

The default set of commands that are proposed are necessary to manage the layouts. The user can then decide to remove or add further commands using the commands Add or Remove Buttons that are found by clicking the small arrow on the right side of the toolbar.

The default commands for the layouts proposed by the toolbar are as follows.

  * Select Previous Layout: Opens the layout that is in the list shown by the combo previous to the one currently loaded.

  * Combo Select Layout: Allows opening any layout available in the list.

  * Select Next Layout: Opens the layout that in the list shown by the combo is next to the one currently loaded.

  * Layout Bar...: Opens the [configuration window for the Layout Toolbar](../WTXSetup/WndSetupLayoutBar/WTXSetupLayoutBar.md).

  * Layout Wizard: Opens the Wizard to create new layouts. The Wizard is described in [Layouts Selection Tab](../Layout/LayoutOverview.md).
