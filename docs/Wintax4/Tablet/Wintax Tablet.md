# Tablet with touch controls

WinTAX4 can run on Tablets with Touch controls.

When used on tablets a set of adaptations and features have been implemented to enable the usage of a touch screen.

With WinTAX4 Tablet commands, the user can replicate all the actions that usually are activated using the mouse. In particular the touch commands manage the configurations, perform zooms operations, change layouts, scroll bars and move windows.

## Windows touch commands

Here’s a quick overview of gestures used to navigate in Windows 8 on a computer with a touch screen.

**Tap**

Tap once on the item.

Opens whatever you tap, similar to clicking with a mouse.

**Press and hold**

Press the finger down and leave it there for a few moments.

Opens a menu specific to what you're doing and it is similar to right-clicking with a mouse.

**Pinch or stretch to zoom**

Touch the screen or an item with two or more fingers, and then move the fingers toward each other (pinch) or away from each other (stretch).

Visually zooms in or out.

**Rotate**

Put two or more fingers on an item and then turn your hand.

Rotates objects in the same direction as you turn your hand. Only some items can be rotated.

**Slide to scroll**

Drag your finger on the screen.

Moves what’s on the screen, it is similar to scrolling with a mouse.

**Slide to rearrange**

This action moves an item. Press and drag an item in the wanted direction.

When you've moved the item to the new location, release it.

It is similar to the drag function with a mouse.

## WinTAX4 Tablet commands

Find below a list of operations that are available when using WinTAX4 on a Touch device.

**Automatic virtual keyboard**

The virtual keyboard is automatically opened whenever the user needs to write in a text field or in a numeric field in edit mode.

**Change layout**

Sliding left or right from a window or from the mainframe: allows you to change the window layout (like when using arrows in layout toolbar.)

**Change configuration page**

Sliding left or right from a window setup: you will change the configuration page.

**Open popup menu**

Press and hold a finger on a window to open popup menu.

**Scroll lists and grids**

Drag the finger on the lists to scroll on the single items. The scroll is also handled on all configuration grids of all windows.

**Scroll cursor values in Graph windows**

Drag the finger on the cursor values on the right side of a graph window to scroll the items up or down.

**Scroll zoom bar in graphic windows**

Drag a finger on a zoom bar (horizontal or vertical) in graphic windows to move the bar left - right or up - down.

**Pinch or stretch to zoom graph**

Touch the window with two or more fingers, and then pinch or stretch the fingers to zoom in or zoom out the graph.

**Zoom box**

To perform a zoom box the user need to perform the following steps:

  * Press and hold on the window to open popup menu.
  * Scroll the menu and select Zoom Box command.
  * Select the desired area with a finger.



**Drag and drop channels from Channel Browser**

Drag the icon of a channel with a finger from one of the pages of the Channel Browser and drop it on the desired window.

**Drag and drop channels from Dataset Panel**

Drag an icon with a finger from one of the pages of the Datasets, Bookmarks and Reference panel and drop it on the desired window.

**Multiple selection of objects in windows and in configuration dialogs**

Multiple selections are achieved by tapping the elements of a list or of a grid that the user wants to select. A tap on a selected item, deselects it. A tap out of the list area deselects all the items. Multiple selections with the tap on the screen are permitted in all windows where it is already possible to do it.
