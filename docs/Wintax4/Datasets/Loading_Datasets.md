## Loading Datasets

### Loading Datasets from the Data Browser

The Data Browser allows to manage Datasets that are available within the workspace. Datasets remain in the workspace until released or replaced.

See also Selection methods

### To load a single Dataset

Proceed as follows to look at just one single selection of data

  1. Open the [Data Browser](../DataBrw/DATA_BROWSER.md)

  2. Click to select a session in the left hand panel

  3. Select laps from the right hand panel using the standard multiple select key combinations or also simply left click and drag to select contiguous laps. Press R to select a whole run

  4. Press Return to load the selection in the first Dataset and return to the main workspace. Any previously loaded Datasets are not cleared




### To load multiple Datasets

Proceed as follows to start from scratch and load in a Dataset group.

  1. Open the [Data Browser](../DataBrw/DATA_BROWSER.md)

  2. Click to select a session in the left hand panel

  3. Select laps from the right hand panel using the standard multiple select key combinations

  4. Press Ctrl+Return (or right click and choose"Add to Comparison") to add the laps to the existing list of Datasets

  5. Repeat steps 2, 3 & 4 until all Dataset to be loaded have been selected. Each Dataset is loaded into the next available slot.




  6. Press Return to go to the workspace

or

  7. Right click Clear Comparison to clear the selection and start again




### To load multiple Datasets to specific slots

Proceed as follows to load Datasets into a particular group of slots.

  1. Open the Data Browser

  2. Click to select a session in the left hand panel

  3. Select laps from the right hand panel using the standard multiple select key combinations

  4. Press Ctrl+ N, where N is 1,2,3,....0, (or right click Add to Dataset) to add the laps to the corresponding slot number

  5. Repeat steps 2, 3 & 4 until all Datasets to be loaded have been selected.




  6. Press Return to go to the workspace

or

  7. Right click on the laps and select Clear Comparison to clear the selection and start again.




###  To clear all Dataset slots

  1. Open the Data Browser

  2. Select File/Clear comparison or click on the toolbar button on the crossed "Libra "
