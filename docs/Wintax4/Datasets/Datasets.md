## Managing Datasets

Datasets is an extension of the data management capabilities of WinTAX4 in which distinct sets of data can be managed simultaneously within the same workspace. The data from different laps/runs can be loaded and at any time it is possible to decide in which window the dataset should be viewed.

A Dataset can be any selection of laps, typically a single lap or a sequence of contiguous laps such as a run.

Up to 10 Datasets can be loaded at the same time.

Note: Datasets replace the previous WinTAX4 concept of Comparison Groups. The difference is that Datasets can be managed more flexibly in the layout window and they are stored in memory until released.

DataSet configurations cannot be saved between working sessions and are not included in the layout configuration window; only the [slot position can be saved](DataSetLayout.md) for each window in layout configuration.
