## Using Help

WinTAX4 - User Guide is a contextual Help which describes the operation of the application WinTAX4. Click on the Help menu or press the F1 shortcut to read information about the selected topic.

###  Buttons

| Hide | Click to show or hide the navigation pane |
| --- | --- |
| Back | Step backwards through topics that have been viewed |
| Forward | Step forwards through topics that have been viewed |
| Print | Print the selected topic or all topics in the selected heading |
| Options | This menu contains some navigations commands. |
  
### Tabs

| Contents | Double-click a book icon to display the help topics.  Click the page icon to view the topic in the main window. Double-click the open book icon to close the book. |
| --- | --- |
| Index | Enter keywords. Double-click a keyword to view the topic |
| Search | Enter a word. Click List Topics to search for topics containing the word. Double-click the topic title to open it in the main window. |
| Favorites | List where you can store your favorite topics and recall them as necessary. |
| Glossary | Search for glossary terms. Click on a glossary term to display a definition |
