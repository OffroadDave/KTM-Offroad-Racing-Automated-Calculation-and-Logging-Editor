## System Requirements

#### Minimum configuration:

| Hardware | Requirement |
| --- | --- |
| CPU | Intel I3 / equivalent AMD processor |
| RAM | At least 2 GB of ram are needed |
| Hard Disk | At least 10 GB of free hard drive space is required. |
| Ethernet | At least 10Mbit (requested for data acquisition) |
  
#### Recommended configuration:

| Hardware | Requirement |
| --- | --- |
| Cpu | Intel Core i7 or i9 / equivalent AMD processor (or faster) |
| Ram | 16 / 32 GB of RAM |
| Ethernet | 10/100/1000 TCP/IP network interface |
| Hard Disk | SSD 512 GB (M2) |
| Display | Full HD |
| OS | Windows 10 |
  
WinTAX is compatible with dual, quad and octa core processors.

WinTAX4 usage is supported with HD and 4K monitors.
