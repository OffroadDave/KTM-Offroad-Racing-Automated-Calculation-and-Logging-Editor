## Window

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Close |  | Closes the window active in the workspace. |
| Close All |  | Closes all windows open in the workspace. |
| Fit Window | Ctrl \+ F | Reduces the active window so that it does not overlap to other windows. |
| Fit All Window | CTRL \+ Shift + F | This command applies the command "Fit Window" to all windows in the layout. The application sequence starts with the window with focus and then proceeds with all other windows depending on their position in the layout. |
| Hide Captions | Alt \+ C | Hides the title bar of all windows. When caption is hidden, in each window appears, with right click, the Windows submenu. |
| Small Caption | K | Small caption allows to reduce the size of windows caption. The command is global and affects all open windows. |
| Standard Caption | K | Standard Caption restores the original caption mode. The command is global and affects all open windows. |
| Cascade |  | Arranges the windows in cascade. |
| Tile Horizontally |  | Reduces all windows to horizontally optimize space. |
| Tile Vertically |  | Reduces all windows to vertically optimize space. |
| Windows... |  | Opens a list containing all windows available. |
| [Wnd1] [Wnd2] |  | List of the open windows; a check mark indicates the active one. |
  
##### Window submenu

The Window submenu contains several commands for managing windows. It is visible only when the window caption is hidden. The menu is the same one that appears when you click the icon of the window if the caption is visible.

  * Restore: The command works when the window is maximized and used to bring it back to normal size.

  * Move: The command changes the cursor and allows the movement the window on the desktop.

  * Minimize: The command works when the window is visible and used to minimize it.

  * Maximize: The command is used to maximize the window size.

  * Close: The command closes the window (Shortcut Ctrl + F4).

  * Next: The command permits to activate the subsequent window (Shortcut Ctrl \+ F6 and Ctrl + Shift + F6 ).
