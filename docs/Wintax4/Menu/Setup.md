## Setup

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| General... |  | Opens the [General Setup](../WTXSetup/WndGeneralSetup/WTXSetupGeneralSetup.md) |
| Channel Parameters | C | Opens the [Channel Parameters Setup](../WTXSetup/WndChannelsParametersSetup/Channels_Parameters.md) |
| Users |  | Opens the Users submenu |
| Accelerators... |  | Opens the [WinTAX4 shortcuts Setup](../WTXSetup/WndSetupAccelerators/WTXSetupAccelerators.md) |
| Data Header... |  | Opens the [Data Header Setup](../WTXSetup/WndSetupDataHeader/WTXSetupDataHeader.md#WndDataHeaders) |
| DataSet Header... |  | Opens the [DataSet Header Setup](../WTXSetup/WndSetupDataHeader/WTXSetupDataHeader.md#WndDataSetHeaders) |
| Channel Browser... |  | Opens the [Channel Browse Setup](../WTXSetup/WndSetupChannelBrowser/WTXSetupChannelBrowser.md) |
| Toolbars... |  | Opens the [Toolbars Setup](../WTXSetup/WndSetupToolbars/WTXSetupToolbars.md) |
| Layout Bar... |  | Opens the [Layout Setup](../WTXSetup/WndSetupLayoutBar/WTXSetupLayoutBar.md) |
| Max Min Setup... |  | Opens the [Max Min Setup](../WTXSetup/MaxMinSetup/MaxMinSetup.md) |
  
####  Users

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Configure Users |  | Allows [creating or modifying a User](../WTXSetup/WndSetupUsers/Users.md) |
| Change User... | CTRL + U | Allows changing the current [User](../WTXSetup/WndSetupUsers/WTXSetupUsers.md) |
| Save As... |  | Copies the current user with a new name |
| Copy User |  | Copies the current user configuration |
| Paste User |  | Pastes previously copied user information (information read with copy) in the current user |
| Export User Snapshot... |  | Saves zss file on disk exporting system and current user setups. For further details see [Export Snapshot](../Tools/Snapshot/Export_Snapshot.md). |
| Import User Snapshot... |  | Opens a .zss file in order to import system configurations. For further details see [Import Snapshot](../Tools/Snapshot/Import_Snapshot.md). |
