## Acquisition

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Acquisition Manager |  | Opens the [Acquisition manager](../Acquisition_Manager/AcqMan.md) |
| Enable/Disable Auto Rx |  | Pause of Auto Rx functions. To disable the Auto Rx, open the [Acquisition manager](../Acquisition_Manager/AcqMan.md) and uncheck Auto Rx in [Rx Task](../Acquisition_Manager/Rx_tasks/Rx_tasks.md) menu. |
| Enable/Disable Auto Rx Remote |  | Pause of Auto Rx on Remote functions. To disable the Auto Rx on Remote, open the [Acquisition manager](../Acquisition_Manager/AcqMan.md) and uncheck Auto Rx on Remote in [Rx Task](../Acquisition_Manager/Rx_tasks/Rx_tasks.md) menu. |
| Enable/Disable Auto Rx Import Lap |  | Pause of Auto Rx on Import Lap functions. To disable the Auto Rx on Import Lap, open the [Acquisition manager](../Acquisition_Manager/AcqMan.md) and uncheck Auto Rx on Import Lap in [Rx Task](../Acquisition_Manager/Rx_tasks/Rx_tasks.md) menu. |
| Update Rx | Alt \+ Ctrl + X | Manual Update RX |
| Cable Download Wizard... |  | Opens the [Cable Download Wizard](../Acquisition_Manager/ACQ_WIZARD/AcqMng_TCPAcqWizard.md) |
| Real-Time Download Wizard... |  | Opens the [Real-Time Download Wizard](../Acquisition_Manager/ACQ_WIZARD/AcqMng_DSTAcqWizard.md) |
| Marvel Download Wizard... |  | Opens the [Marvel Download Wizard](../Acquisition_Manager/ACQ_WIZARD/Marvel_Wizard.md) |
| USB/FlashCard Download Wizard... |  | Opens the [Flash Card Download Wizard](../Acquisition_Manager/ACQ_WIZARD/Flash_Card_Wizatrd.md) |
| DVR Download Wizard... |  | Opens the [Data Video Recorder Download Wizard](../Acquisition_Manager/ACQ_WIZARD/AcqManager_DVRStartupWizard.md) |
| CAN Download Wizard... |  | Opens the [CAN Download Wizard](../Acquisition_Manager/ACQ_WIZARD/AcqMng_CANAcqWizard.md) |
| Session Startup Wizard... |  | Opens the [Session Startup Wizard](../Acquisition_Manager/ACQ_WIZARD/AcqMng_SessionStartupWizard.md) |
