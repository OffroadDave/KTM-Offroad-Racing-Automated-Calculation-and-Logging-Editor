## Options

The contextual menu changes based on the currently selected Window. If no windows are open, the menu will be empty. See [Analysis Windows](../AnalysisWnds/AnalysisWndsOverview.md) for details.

### Import / Export Window

Regardless of the selected window, the "Options" menu will show the following two items:

  * Import Window

  * Export Window




These commands allow you to save or load the content of the currently selected window to/from a file.

**Export Window:** Use this command to export (save) the content of the current window. You will be prompted to choose a destination folder and filename. By default, the file browser opens to the export path set in General Setup, and will remember the last folder used. The exported file keeps its original format and extension.

**Import Window:** Use this command to import (load) a window from a previously saved file. You will be prompted to select the file to open. By default, the file browser opens to the export path set in General Setup, and will remember the last folder used. The imported window will be opened over the existing windows, but it is not automatically added to the current layout or saved unless you do so manually.

If a file with the same name already exists, you can choose to overwrite it or rename the file.
