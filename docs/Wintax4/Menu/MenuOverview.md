## Menu Overview

In the main window of WinTAX4 the following menus are available:

| MENU | DESCRIPTION |
| --- | --- |
| [File](File.md) | Commands to load data to manage the layouts, the print, the loading and the saving of single windows. |
| [Edit](File.md) | Standard commands for Undo/Redo, Cut, Copy and Paste. |
| [View](View.md) | Commands to display the Toolbars, the working windows, management of Finish Line, Track Section and Split Time. |
| [Data](Data.md) | Commands to manage the loaded data. |
| [Graphs](MenuGraphs.md) | Commands to display and load the analysis windows. |
| [Options](Options.md) | Commands to select the analysis window. |
| [Setup](Setup.md) | Commands to configure the WinTAX4 environment. |
| [Tools](Tools.md) | Commands to access working instruments of WinTAX4 |
| [Acquisition](Acquisition.md) | Commands to manage the acquisition. |
| [Window](MenuWindow.md) | Commands to display the windows. |
| [Help](Help.md) | Commands to display the Info of WinTAX4, access to Help, WinTAX4 Update |
  
Many commands are also available with [Keyboard Shortcuts](../Shortcut/Overview.md).
