## File

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Open Data... | F3 | Opens the [DataBrowser](../DataBrw/DATA_BROWSER.md). |
| Load Layout... | Alt \+ Y | Loads a Layout (collection of Windows) from the disk. |
| Layout Wizard |  | Opens the layout wizard window which creates custom layouts. |
| Save Layout | Y | Saves the current Layout on the disk. |
| Save Layout As... |  | Saves As of the current Layout. |
| Load Window... |  | Loads a Window of the same type of the focused one. It requires at least one open window. |
| Save Window | Ctrl \+ S | Saves the current window. It requires at least one open window. |
| Save Window As... |  | Saves As of the current window. It requires at least one open window. |
| Save All Windows | Ctrl \+ Shift + S | Saves all open windows. |
| Export Layout |  | Allows to export in a .ZLY compressed file a snapshot of only the layout with the related windows. |
| Import Layout |  | Allows to import from a .ZLY compressed file a snapshot of only the layout with the related windows. |
| Multi Display |  | When enabled, allows the visualization of WinTAX on multiple viewers that can be visualized on multiple screens. |
| Print Setup... |  | Opens the [Print setup](../WTXSetup/PrintSetup/PrintSetup.md). |
| Print Window |  | Prints the current Window. It requires at least one open window. |
| Print Layout | Shift \+ P | Prints the current Layout. It requires at least one open window. |
| Print Window to Clipboard | Ctrl \+ Shift + W | Copies the image of the current window in the Windows Clipboard. |
| Print Layout to Clipboard | Ctrl \+ Shift + L | Copies the image of the current layout in the Windows Clipboard. |
| Exit |  | Exit from WinTAX4. With or without confirmation, depending on the status of the flag which is located here: Menu Setup, page General Options, section Application, command Ask Confirm Before Exit the Application... |
