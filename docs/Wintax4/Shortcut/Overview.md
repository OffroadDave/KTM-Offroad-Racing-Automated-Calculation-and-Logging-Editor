## Keyboard Shortcuts Overview

Keyboard shortcuts are a combination of keystrokes that provides easier access to WinTAX4 commands.

WinTAX4 divides the shortcuts in the following categories

  * [General keyboard shortcuts](Shortcut.md): these are the keyboard shortcuts related to the [WinTAX4 menu](../Menu/MenuOverview.md).

  * [Analysis windows keyboard shortcuts](WindowsShortcuts.md): these are the keyboard shortcuts related to the [analysis windows](../AnalysisWnds/AnalysisWndsOverview.md).

  * [Data Browser keyboard shortcuts](DataBrowserShortcut.md): these are the keyboard shortcuts related to [Data Browser](../DataBrw/DATA_BROWSER.md).
