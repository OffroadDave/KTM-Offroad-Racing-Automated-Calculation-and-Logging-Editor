## Popup Alarms

This window is displayed only when there is at least one alarm in real-time; it is not possible to open it manually. A pop-up window appears for each [enabled alarm.](../../WTXSetup/WndChannelsParametersSetup/Channels_Parameters.md#Alarm) A subsequent alarm related to the same channel uses the same window; alarms of different channels open new pop-up windows.

You can do the following for each pop-up window:

Close: it closes the alarms window of that channel; the window will appear again the next time that alarm triggers. If different alarms have already triggered on that channel, each time you press Close, you will go back to the alarm right behind it.

Hide: it closes the window concerning the alarms of that channel; when subsequent alarms are triggered, it will remain hidden. To re-activate the pop-up window referred to the alarms of that channel, select the Tool – Alarms – View menu from WinTAX4 and re-activate the hidden alarm.

Hide All: it closes the pop-up windows concerning all the alarms. To re-activate the pop-up windows, proceed in the same way as for the Hide function.

Go - To: it launches a [freeze](../../AnalysisWnds/Wnds/GRA/GRAWndFeatures.md#FreezeRTAnalysis) command that blocks the windows and takes the cursor to the alarm selected. Press the button again to restore normal operation.
