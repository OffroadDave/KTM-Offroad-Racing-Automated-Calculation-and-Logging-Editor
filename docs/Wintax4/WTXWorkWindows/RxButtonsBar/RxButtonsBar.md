## Rx Buttons Bar

The buttons in the dockable toolbar enables viewing and changing statuses of the configured RxTasks and contains the following buttons (some of the buttons might be disabled depending on the RxTasks configured in the [Acquisition Manager](../../Acquisition_Manager/Rx_tasks/Rx_tasks.md))

    * A RX Enables / Disables AutoRx

    * R RX Enables / Disables AutoRx Remote

    * i RX Enables / Disables AutoRx Import Lap

    * D RX Enables / Disables [Intelligent Data Loading](../../Acquisition_Manager/Intelligent_Data_Loading/Intelligent_Data_loading.md) (Available only for some licenses)




It is possible to enable or disable this toolbar visualization using the "View/Rx command Buttons Bar" menu.

The button colors will change based on the status of the functions they are associated with:

  * Grey button with black text: Acquisition is ready and waiting for new data.

  * Grey button with grey text: Acquisition is disabled.

  * Blinking red and grey: new data is available and has been loaded.

  * Blinking red and yellow: new data is available but has not been loaded.
