### Run Preview Window Overview

The window can be displayed or hidden through View/Run Preview command of the main menu. The window is dockable and it can be resized on demand. The window is like an extended [graph window](../../AnalysisWnds/Wnds/GRA/GRAWndOverview.md) which is able to show channels on the whole run of the selected laps.
