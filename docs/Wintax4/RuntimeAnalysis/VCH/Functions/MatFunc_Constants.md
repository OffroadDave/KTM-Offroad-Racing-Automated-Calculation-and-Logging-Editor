###  Constants

#### pi

p

Returns the value of the ratio of any circle's circumference to its diameter in Euclidean space; pi = 3.1415926536.

#### gcost

gravitational acceleration

Returns the medium Earth's gravitational acceleration at sea level; g = 9,80665 m/s2.

#### ecost

e constant is Napier's (or Euler's ) number

Returns the value of base of the natural logarithm; e = 2.718281828.

#### norx

Invalid data

Returns the value used in math expressions to identify invalid data. Data marked as invalid will not be considered during computation.

#### intmax

Returns the maximum integer value; INTMAX = 2147483647

#### intmin

Returns the minimum integer value; INTMIN = -2147483648

#### realmax

Returns the maximum positive value; REALMAX = 1.7976931348623158e+308

#### realmin

Returns the minimum positive value; REALMIN = 2.2250738585072014e-308
