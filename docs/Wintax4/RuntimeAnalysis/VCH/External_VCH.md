### External maths channels

In addition to native internal Math functions, it is possible to create Math channel in other two ways:

  * Math Channels can be created externally via [Scripting](../../Scripting/ScriptExamples/vch_script.md)



  * Math Channels can be created externally via user-generated [Math DLLs](DLL_Maths.md) (an example DLL project is installed in WinTAX4\Samples\MathDll.zip)
