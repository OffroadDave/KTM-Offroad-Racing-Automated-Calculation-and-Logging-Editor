Some licenses allow improving of the VCH channel expression using some programming language statements.

The VCH programming language statements are categorized into this following types:

  * Declaration Statements: [dim](statements.md#vch_StatDim), [static](statements.md#vch_StatStatic).

  * Conditional Statement: [if](statements.md#vch_StatIfElse), [else](statements.md#vch_StatIfElse).

  * Iteration Statements: [for](statements.md#vch_StatFor), [while](statements.md#vch_StatWhile).

  * Jump Statements: [break](statements.md#vch_StatBreak), [continue](statements.md#vch_StatContinue), [return](statements.md#vch_StatReturn).




If an expression uses statements, the expression can be written and expanded on more than one line of the editor. The line must be terminated with ";". it is possible to insert comments using "//".
