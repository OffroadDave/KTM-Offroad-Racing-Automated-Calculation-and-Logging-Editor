## Analysis Windows Overview

The Analysis windows allow to display and analyze the graphic elements available in each graph window. The user can carry out the basic functions of the window, have access to the specific commands and recall advanced functions that involve also other windows. Each type of window has specific commands that can be reached both from the main menu of the application, from the dedicated [toolbars](../Toolbars/Toolbars.md), [keyboard shortcuts](../Shortcut/WindowsShortcuts.md#ShortcutListWindows) and from the pop-up menu. The look and the behavior of each window can be modified or customized through the configuration interfaces.
