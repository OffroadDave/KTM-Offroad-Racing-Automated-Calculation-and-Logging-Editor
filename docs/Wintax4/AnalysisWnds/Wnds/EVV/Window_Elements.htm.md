### Window Elements

  * Channel Name: displays the name of the VCH
  * Editable Value Field: displays the value and allows inline editing



This layout is visually similar to the "Display Value" window, but values are editable.

### Editing Behavior

To edit a value it is possible to double click on its cell and write the new value. It is possible to update multiple channels and then apply all changes: The changes are applied when the button "Update Edit VCH" is pressed.

Changes made in the Edit VCH Value window are automatically synchronized across all windows.
