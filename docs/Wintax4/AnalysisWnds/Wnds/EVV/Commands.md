### Commands

The main commands available in the [Edit VCH Value window](Window_Elements.htm.md) window can be enabled through

  * the Options menu in the main menu of the application

  * the buttons of the dedicated Toolbar

  * the popup menu that can be displayed by clicking with the right button of the mouse on the graphic area of the window.




###### Layout

Displays the Layout submenu with the following commands that allows selecting the arrangement mode of the graphs:

  * Horizontal \- The window organizes all channels in a horizontal manner.

  * Vertical \- The window organizes all channels in a vertical manner.

  * Auto \- The window organizes all channels to fill the window space in the best possible way.




#### Toolbar

The toolbar of the windows allows the access to the following commands:

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Load |  | Loads a configuration window to select a configuration corresponding to a Edit VCH Value configuration window. |
| Save |  | Saves the current window configuration on a file. |
| Layout orientation |  | This option lets you arrange the displayed values in horizontal, vertical, or automatic mode. |
| Properties |  | Opens the interface to configure the Edit VCH Value configuration window |
| Update Edit VCH |  | This option allows applying the changes made to the Edit VCH Window. The button is disabled if no changes are detected. |
  
#### Pop-up Menu

By clicking with the right button of the mouse on the graphic area of the window the pop-up menu is displayed that allows the access to the following commands:

| COMMAND | DESCRIPTION |
| --- | --- |
| Print Window to Clipboard | Copy the image of the window in the current state on the clipboard. |
