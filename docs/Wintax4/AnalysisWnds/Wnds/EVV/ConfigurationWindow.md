### Configuration Window

The Edit VCH Value Configuration window allows setting the look of the window.

#### Window Options:

• Custom Color: Enables the option to set a color scheme for the text and background of each Channel.

• Window: customize background color for the entire window

• Font: choose fonts separately for label and value columns

• Layout: select vertical, horizontal or automatic orientation for the window

#### Graphs Options (per VCH):

• Label: shows the name of the channel (non-editable)

• Color label: customize text and background color for the label column

• Color value: customize text and background color for the value column

• Enabled: Enable to show the selected display name.

• Display name: define a custom label for the channel (shown instead of the original name)

• Unit: optional field to show a unit near the value (configurable in the Virtual channel window).
