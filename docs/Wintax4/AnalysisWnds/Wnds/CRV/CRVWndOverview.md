### Track Window Overview

The Track window shows the track set in the [Track Editor](../../../Tools/TrackEditor/Track_Editor.md). Moreover it allows viewing the Section Track configured in the [Track Editor](../../../Tools/TrackEditor/Track_Editor.md). In addition reports concerning the sections, events and markers linked to the channels can be displayed. The track can also be customized by manually adding labels, sections and markers. The vehicle on the track can be linked to the position of the cursor in the Graph window.
