### Configuration

This page contains some common configurations

#### 

#### Lap Filter

Displays the setting to enable the lap filter. The "lap filter" is an additional filter on the laps used to filter out data from the calculations. To modify the setting and filter the laps, modify the edit window of the filters.

  * Enable: enables the customized settings

  * Acquisition

  *     1.        * Source: the laps are filtered according to the data origin: All no filter is applied, Cable filters using only the cable data (files cableData.ztx), Real time filters considering only the data acquired in real time (files dstData.ztx), Radio keeps the compatibility with files of WinTAX2 and WinTAX3 and refers to a *.dtx file.

  * Runs



  *     1.        * All Runs: selects all runs

       * Runs: filters keeping all runs specified in the list of the text box. The comma is used to list more runs or a double dot to define an interval (Example: 1,2,3,10..12)

       * Last: selects the last run

  * Date / Hour

  *     1.        * All Laps: It is by default and selects all laps of the run

       * Find all laps acquired:

       *          * Between: filters only the laps acquired in the set time range

         * During the previous: filters only the laps acquired in the last hours set.

  * Lap Markers Section:

  * The filter is enabled according to the Markers selected. By default everything is selected. The Markers are information container inside each lap and define the type of Lap. The two buttons on the options bar are used to select all markers or to deselect them all.

  * The Lap Marker section could be a different number of Lap Marker, depending on Window type. The main image shows all markers, instead the image below shows a smaller number of markers, as in Section Time Report Window.




#### Font Configuration

Settings Local Fonts. The windows allows changing the default font that will be used in the Analysis Windows if no customized font is set.

  * Family Font: Sets the type of font choosing an item in the combo list.

  * Font Dimension: Sets the size of the font.

  * Scalable: Sets the size automatic adaptation of the font in relation to the window size. Sometimes this option could be hidden.




In some windows it is possible only to configure the type of font. It is possible to select a custom font for all the text elements. All text will be automatically scaled when resizing the window.

Sometimes, in this configuration, it is possible to choose the 7 Segments font instead of the list of configurable fonts.
