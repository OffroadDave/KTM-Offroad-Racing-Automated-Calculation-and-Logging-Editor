### Window Elements

# 

The window is formed by cells arranged by row and column. Rows represent a single occurrence of an event, columns represent all the values connected with those occurrences.

The Event Report window can be configured to contain the following information:

  * Name: Event name and bit label (for bitmapped diagnostics)

  * Group: Event group name

  * TimeInLap: Event time from start of lap (sec, resolution 1ms)

  * Date: Event date (dd/mm/yy)

  * Time: Event timestamp (hh:mm:ss.mmm)

  * Count: number of occurrences within current data selection

  * DeltaTime: time elapsed since last event of same type

  * DeltaSpace: distance covered since last event of same type

  * Markers: The values of multiple marker channels taken at the event time (or at the time offset from the event, if defined in the event properties)

  * SECU Status: Comments related to the SECU events.

  * Lap header information (configurable) from lap in which event was detected
