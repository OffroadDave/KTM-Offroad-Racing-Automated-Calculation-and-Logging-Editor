### Events Report Window Overview

The Event Report shows selected events which occurred in the current session for the selected vehicle (see also [Diagnostics Report](../DGS_REPORT/DGSREPWndOverview.md) ). Multiple event windows may be included in any layout, each one showing a different selection of events.

The cursor connect feature allows using the event report to find occurrences of events within the graphs just by clicking on the relevant entry in the report and moving up and down with the arrow keys.

Thus, event report windows work as search filters which can be used to step through the data looking for selected events.
