### Functions

The Event Report window has the following functions:

  * Freeze Real time Analysis.




#### Freeze Real time Analysis

Acquisition can be paused during normal running and real time data, up to a maximum of 180 seconds since the current time, frozen in order to allows user to work as in post processing analysis.

This function affects all real time windows displayed in the layout. When freeze condition is unlocked, all windows return to the normal real time state and frozen data won’t be saved on disk. Command is available by clicking with the mouse left button on a row of the report.
