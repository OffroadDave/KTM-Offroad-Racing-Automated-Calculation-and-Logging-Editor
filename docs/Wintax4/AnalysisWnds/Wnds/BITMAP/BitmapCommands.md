### Commands

The main commands available in the Bitmap window can be enabled through

  * the Options menu in the main menu of the application

  * the buttons of the dedicated Toolbar,

  * the popup menu that can be displayed by clicking with the right button of the mouse on the graphic area of the window.




#### Options Menu

Through the Options menu of the Bitmap windows the following commands can be enabled:

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Layout |  | Displays the Layout submenu. |
| Properties | E | Opens the interface to configure the window |
  
#### Layout

Displays the Layout submenu with the following commands:

  * Original size: The image must not be stretched, but will have to maintain its original size; it is aligned to the top and to the left borders of the window. The window shows only a section of the picture when the window is smaller than image; otherwise a part of the windows is filled with the background color. 




  * Center: The image is drawn with the rules described in Original Size, but it is centered in the middle of the window.




  * Stretch: The image is adapted to window size.




  * Fit: The image is adapted to window size but maintains original ratio




#### 

#### Toolbar

The toolbar of the windows allows the access to the following commands:

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Load |  | Opens a configuration window to select a configuration corresponding to a Bitmap View window. |
| Save |  | Saves the current window configuration on a file. |
| Properties | E | Opens the interface to configure the Bitmap View window |
  
#### Pop-up Menu

By clicking with the right button of the mouse on the graphic area of the window the pop-up menu is displayed that allows the access to the following commands:

| COMMAND | DESCRIPTION |
| --- | --- |
| Print Window to Clipboard | Copy the image of the window in the current state on the clipboard. |
| Window | Opens the [Window submenu](../../../Menu/MenuWindow.md#MenuWindow_submenu) |
