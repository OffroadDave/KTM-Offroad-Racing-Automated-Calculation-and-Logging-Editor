### Numeric Table Window Overview

The Numeric Table Window shows for each configured channel the values calculated on the lap loaded in the time ranges determined by the frequency set on the window. The position of the cursor in a [Graph](../GRA/GRAWndOverview.md) window is highlighted on the "Numeric Table" by selecting the row corresponding to the previous value.

In case of comparison, this window will always show the first enabled dataset.
