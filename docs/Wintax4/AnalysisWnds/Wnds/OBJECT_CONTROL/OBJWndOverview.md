### Object Control Window Overview

An Object Control Window can contain an ActiveX control or an embedded program. This allows external programs to be run within the WinTAX4 environment. The Object Control Window can be manipulated in the same way as the other windows. It can be for example placed in a layout. The main function of this window is to manage WinTAX4 data and events from ActiveX Control. However, the window can also be used to incorporate external programs. The figure above shows a word document embedded in WinTAX4.

The embedded program or control object is added to the Object Control Window display from the [Configuration Window](Configuration_Window.md).
