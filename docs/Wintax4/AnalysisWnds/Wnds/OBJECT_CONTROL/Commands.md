### Commands

The main commands in the [Object Control Window](OBJWndOverview.md) can be enabled through:

  * the Options menu in the main menu of the application

  * the buttons of the dedicated Toolbar,

  * Pop-up menu that can be displayed by clicking with the right button of the mouse on the graphic area of the window.




#### Options Menu

The Options menu allows the access to the following commands:

| COMMAND | DESCRIPTION |
| --- | --- |
| Properties | Opens the interface to configure the window. |
  
#### 

#### Toolbar

The toolbar allows the access to the following commands:

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Load |  | Opens a window to select a configuration file corresponding to a object control window. |
| Save |  | Saves the present window configuration on a file. |
| Properties | E | Opens the interface to configure the object control window. |
  
If ActiveX Control handles its dedicated toolbar, it will be loaded on WinTAX4, like excel in picture below.

When the ActiveX Control contains an Embedded Program, the WinTAX4 environment (the menus and toolbars) are replaced by the environment of the embedded programs.

## Pop-up menu

By clicking with the right button of the mouse on the graphic area of the window, the pop-up menu is displayed only if managed by ActiveX Control.
