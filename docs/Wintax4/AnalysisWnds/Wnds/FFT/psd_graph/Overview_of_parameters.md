### Overview of setup parameters

# 

  * Frequency analysis types: Power Spectral Density, Magnitude, Phase 

  * FFT length (32, 64,…., 512, 1024)

    * Defines the number of discrete frequency bins in the spectrum

    * It is also related to the number of samples used to calculate the spectrum

    * The higher the length the greater the number of samples used 

  * Definition

    * Determines the frequency resolution of the spectrum

    * Definition = 1 is the highest resolution, 4 is the lowest

    * The higher the resolution the more samples are used to calculate the spectrum 

  * Window

    * Windowing is a technique used to reduce the distorting effects of FFT. It is beyond the scope of this guide
