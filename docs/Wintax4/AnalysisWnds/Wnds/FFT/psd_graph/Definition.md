### Definition

  * This example shows how the Definition affects the spectra

  * With increasing Definition number the frequency components become spread out

  * The best results are obtained with Definition = 1

  * It may be necessary to use other values depending on the number of samples available (next slide)

  * For example the best result is obtained with FFT = 1024 and Def = 1but this requires an acquisition of at least 2048 samples
