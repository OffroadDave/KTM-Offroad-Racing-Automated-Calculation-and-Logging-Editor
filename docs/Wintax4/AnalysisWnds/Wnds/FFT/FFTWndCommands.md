### Commands

The main commands in the [FFT Analysis Window](FFTWndOverview.md) can be enabled through:

  * the Options menu in the main menu of the application

  * the buttons of the dedicated Toolbar,

  * Pop-up menu that can be displayed by clicking with the right button of the mouse on the graphic area of the window, on the Info boxes and on the Y scales of the selected channels.

  * Keyboard shortcuts




The commands are distinguished according to Mode (Frequency Analysis or Spectrogram)

#### Options Menu

The Options menu allows the access to the following commands:

##### Frequency Analysis Mode

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Clear Selection |  | De-select all the channels selected in the window. |
| Select All Channels | Ctrl \+ A | Select all channels in the window. |
| View |  | Shows the View submenu. |
| Mode |  | Switch between Frequency Analysis Mode and Spectrogram Mode |
| Open in Excel | Shift \+ X | Opens an Excel sheet containing the X and Y values for each available channel taking also into account possible comparisons. |
| Switch to Telemetry/Post Processing | Ctrl \+ T | Enables to switch from the Post-Processing mode to the Telemetry mode and vice versa. |
| Freehand Drawing |  | List of commands that are used to draw or write texts on the window. See [here](../../../Toolbars/ToolbarFreeHand.md) for a complete description of the commands. |
| Properties | E | Opens the interface to configure the window. |
  
##### 

###### View

Shows the pop-up sub menu to select the graphic elements of the window that can be shown or hidden. The displayed elements are highlighted with a check mark on the left. Show All & Hide All show and hide all elements respectively.

#### Pop-up menu

##### Frequency Analysis Mode

By clicking with the right button of the mouse on the graphic area of the window, the following pop-up menu is displayed:

This section will describe only the commands that have not already been described previously.

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Print Window to Clipboard |  | Copy the image of the window in the current state on the clipboard. |
| Window |  | Opens the [Window submenu](../../../Menu/MenuWindow.md#MenuWindow_submenu) |
| Copy Data to Clipboard | Ctrl \+ Shift + C | Copies to clipboard of Windows the X and Y values for each channel available taking also into account possible comparisons. |
  
By clicking with the right button of the mouse on an Info box or on the Y Scale of a channel, the following pop-up menu is displayed:

This section will describe only the commands that have not already been described previously.

| COMMAND | DESCRIPTION |
| --- | --- |
| Remove Graph | Removes the selected channels. |
  
##### Spectrogram Mode

This section will describe only the commands that have not already been described previously.

| COMMAND | SHORTCUT | DESCRIPTION |
