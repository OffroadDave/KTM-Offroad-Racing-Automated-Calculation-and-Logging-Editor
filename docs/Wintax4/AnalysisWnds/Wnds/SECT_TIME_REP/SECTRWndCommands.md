### Commands

The main commands available in the window can be enabled through

  * the Options menu in the main menu of the application

  * the buttons of the dedicated Toolbar ,

  * Pop-up menu that can be displayed by clicking with the right button of the mouse on the graphic area of the window.




#### Options Menu

The Options Menu allows the access to the following commands:

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Mode |  | Chooses one of the three display modes: Session, Run, Selected |
| Show Delta Time |  | Shows the difference between the best sectors. |
| Highlight Range |  | Shows the sectors nearest to the best one (configurable percentage of difference and background color). |
| Refresh |  | Recalculates report. |
| Stop Operations | Esc | Stops recalculating (available only when report is recalculating). After stop, report shows partial results. |
| Export |  | Exports report as csv, txt (text files), xls (Microsoft Excel). |
| Copy to Clipboard | Ctrl \+ Shift + X | Copies the value of the cells for external applications. |
| Open in Excel | Shift \+ X | Opens the Sections Time report window in Excel. |
| Properties | E | Opens report configuration. |
