### XY Window Overview

An XY window shows the distribution of the sampled values of one or more channels on the Y-axis in relation to the series of sampled values of a reference channel configured on the X-axis.

By setting the display mode, the distribution of the remarks can be displayed:

  * as series of points (Graph mode)

  * as a map (Smooth mode)

  * as text values (Percent mode).




The data on Graph mode can be analyzed in detail by zooming or interpolating them with Best Fit function; it is also possible to configure the graphic features of the elements of the window for more detailed visualization.
