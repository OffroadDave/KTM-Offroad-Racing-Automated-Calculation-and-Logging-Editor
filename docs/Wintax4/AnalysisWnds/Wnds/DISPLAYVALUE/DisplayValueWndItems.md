### Window Elements

The Display Value window is formed by the value area.

#### Value Area

The value area is split into as many cells as the number of valid configured channels; each cell can display two or more rows. The first row shows the label name or the alternative text if configured. The second row usually shows the values of the channel at the current position. 

In case of comparison a small colored square to the left side of the channel will be shown to identify the related lap. This windows supports up to 11 datasets: 10 laps + 1 reference lap.

Each lap will be visualized with a small square of the same color of the dataset available in the data header.

A row for the channel unit measure can optionally be shown under the channel name. On the left of each data set value, an icon optionally shows the trend of the channel, calculated as difference between the value at current sample and the previous one.
