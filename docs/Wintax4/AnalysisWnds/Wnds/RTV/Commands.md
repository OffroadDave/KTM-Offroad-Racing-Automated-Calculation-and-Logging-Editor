### Commands

From the option menu the following commands are available:

Play: Starts streaming video

Pause: Pauses current video stream

Stop: Stops the video stream

Properties:  Opens the configuration dialog

Pop-up Menu

Right-clicking on the video area displays a context menu with the same commands as in the Options menu. This provides quick access to playback and configuration tools.

Right clicking on the video area of the window, gives another access to the above commands with the addition of the following command: 

Print Window to clipboard: Copy the image of the window in the current state on the clipboard.
