### Configuration Window

Access the configuration properties via:

  * Options > Properties

  * Double-click on the video area

  * Right-click menu > Properties




### Configuration page

  * Custom color: When enabled allow the selection of a background color for the real time video window.

  * RTSP/RTP URL: full connection string, e.g.: rtsp://admin:password@192.168.1.10:554/Streaming/Channels/101/

  * Transport: Only when a RTSP URL is used, the Transport mode can be modified. It allows selecting between TCP or AUTO mode.




Note: If the same URL is already playing in another window of the same layout, a warning will be shown when trying to start another stream.
