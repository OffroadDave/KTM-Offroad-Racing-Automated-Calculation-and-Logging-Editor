### Alarms Window Overview

The Alarms window includes all channels that in "Setup \- Channel Parameters" contain configured alarms. The window can be configured to become part of a Layout. The window can be configured so that it will open when an alarming situation occurs.

An alarm can be associated with each type of channel according to the following modes:

  * By setting a range within which the channel is in alarm, configuring Min and Max Limits..

  * By setting a further range, called Valid Range, within which the permitted values are configured. If the alarm is correctly configured, Min and Max Limits are completely included in the Valid Range.




The alarm configuration occurs in the [channel parameters](../../../WTXSetup/WndChannelsParametersSetup/Channels_Parameters.md#Alarm) setup. Alarm situations are also recognized using alias channels.

Only one Alarm window can be displayed. Any attempt to open the Alarms window when it is already displayed, leads only to focus the window itself.
