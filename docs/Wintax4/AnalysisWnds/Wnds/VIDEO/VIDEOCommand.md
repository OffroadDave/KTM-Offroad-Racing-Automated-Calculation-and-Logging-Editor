### Commands

The main commands available in the [Multimedia](VIDEOFeatures.md) window can be enabled through

  * the Options menu on the main menu of the application

  * the buttons of the dedicated Toolbar ,

  * Pop-up menu, which can be displayed by clicking with the right button of the mouse in the graphic area of the window, on the Info boxes or on the Y scales of the selected channels.




#### Options Menu

The Options menu allows access to the following commands:

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Previous Frame |  | Seeks video to the previous frame |
| Rewind |  | Rewinds the media to the starting position with high frame speed |
| Play |  | Plays the media content |
| Pause |  | Pauses the media content |
| Stop |  | Stops the media content |
| Forward |  | Forwards the media to the end with high frame speed |
| Next Frame |  | Seeks video to the next frame |
| Sound On/Off |  | Enables and disables sound in video. |
| Synchronize Video Data |  | Inserts a time offset in video frame from a graph window. |
| Clear Video Synchronization |  | Resets the time offset. |
| Zoom In |  | Zooms the graphic area with respect to the X axis. |
| Zoom Out |  | Operation opposite to Zoom In |
| Minimum Zoom |  | Displays the graphic area with respect to the whole interval of the X axis |
| Select Layout |  | Selects the layout of the window, horizontal and vertical. In both cases the frames are resized keeping the original aspect ratio. |
| Stop Operations | ESC | Stops zoom operations. |
| Properties | E | Opens the interface to configure the window. |
  
#### 

#### Synchronize Video Data

Inserts a time offset in video frame from a graph window. it is active only if a graph window is present in the layout. A message appears in the graph window to give instructions regarding the offset settings.

#### 

#### Toolbar

The toolbar enables the following commands:

| COMMAND | DESCRIPTION |
| --- | --- |
| Load | Opens a window to select a configuration file. |
| Save | Saves the window configuration on a file. |
| Properties | Opens the interface to configure the window. |
| Previous Frame | Seek video to the previous frame |
| Rewind | Rewind the media to the starting position. |
| Play | Play the video content |
| Pause | Pause the video |
| Stop | Stop the media content |
| Forward | Forward the media to the end |
| Next Frame | Jump video to the next frame |
| Sound On/Off | Enable and disable sound. |
| Zoom In | Zooms the graphic area in respect to the X axis. |
| Zoom Out | Operation opposite to the Zoom In |
| Minimum Zoom | Displays the graphic area in respect to the whole interval of the X axis |
  
#### 

#### Pop-up menu

By clicking with the right button of the mouse on the graphic area of the window, a pop-up menu is displayed. It shows the same commands of the Options Menu, except for the following command

| COMMAND | DESCRIPTION |
| --- | --- |
| Window | Opens the [Window submenu](../../../Menu/MenuWindow.md#MenuWindow_submenu) |
| Print Window to Clipboard | Copy the image of the window in the current state on the clipboard. |
