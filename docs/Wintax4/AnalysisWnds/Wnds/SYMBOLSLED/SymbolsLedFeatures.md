### Symbols Led Window Overview

The Symbols Led window displays a bitmap or a led set by user that depends on the value assumed by a channel in relation to the configured conditions. The bitmap is shown at the instant of the Real Time acquisition or at the current position of the cursor in the Post Processing analysis. The window works with the working dataset and can manages one or more channels. The user also has the option to view the name and the value assumed by the channel. The window can also manage alarms and out of range values.

The maximum number of channels that can ben inserted in a window is 128 and the maximum number of allowed conditions for each channel is 16. The conditions are read in sequence: if one is verified, the following are ignored; if it is not verified, the next will be examined. If none of the conditions are checked, the window displays the text configured in Channel section. 

##### Compare mode:

  * In compare mode this window displays data from one dataset. 
  * If more than one dataset is available and enabled, values and colors that are visualized are of the first enabled dataset.
