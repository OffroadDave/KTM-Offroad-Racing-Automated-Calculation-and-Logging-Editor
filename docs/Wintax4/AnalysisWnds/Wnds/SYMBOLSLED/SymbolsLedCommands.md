### Commands

The main commands available in the Symbols Led window can be enabled through

  * the Options menu in the main menu of the application

  * the buttons of the Toolbar dedicated,

  * the popup menu that can be displayed by clicking with the right button of the mouse on the graphic area of the window.




#### Options Menu

Through the Options menu for the Symbols Led windows the following commands can be enabled:

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Layout |  | Displays the Layout submenu. |
| Switch to Telemetry/ Post Processing | Ctrl \+ T | Enables to switch from the Post-Processing mode to the Telemetry mode and vice versa. |
| Properties | E | Opens the interface to configure the window |
  
#### 

###### Layout

Displays the Layout submenu with the following commands that allows selecting the arrangement mode of the graphs:

  * Horizontal \- The window organizes all channels in a horizontal manner.

  * Vertical \- The window organizes all channels in a vertical manner.

  * Auto \- The window organizes all channels to fill the window space in the best possible way.




#### 

#### Toolbar

The toolbar of the windows allows the access to the following commands:

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Load |  | Opens a configuration window to select a configuration corresponding to a Symbols Led window. |
| Save |  | Saves the current window configuration on a file. |
| Properties | E | Opens the interface to configure the Symbols Led window |
| Horizontal |  | The window organizes all channels in a horizontal manner. |
| Vertical |  | The window organizes all channels in a vertical manner |
| Auto |  | The window organizes all channels to fill the window space in the best possible way. |
| Switch to Telemetry/Post Processing | Ctrl + T | Enables to switch from the Post-Processing mode to the Telemetry mode and vice versa. |
  
#### Pop-up Menu

By clicking with the right button of the mouse on the graphic area of the window the pop-up menu is displayed that allows access to the following commands:

This section will describe only the commands that have not already been described previously.

| COMMAND | DESCRIPTION |
| --- | --- |
| Print Window to Clipboard | Copy the image of the window in the current state on the clipboard. |
| Window | Opens the [Window submenu](../../../Menu/MenuWindow.md#MenuWindow_submenu) |
