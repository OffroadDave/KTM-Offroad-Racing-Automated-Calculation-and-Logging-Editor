### Commands

The main commands in the [G-G Diagram Window](GGFeatures.md) can be enabled through:

  * the Options menu in the main menu of the application

  * the buttons of the dedicated Toolbar,

  * Pop-up menu that can be displayed by clicking with the right button of the mouse on the graphic area of the window, on the Info boxes and on the Y scales of the selected channels.

  * Keyboard shortcuts




#### Options Menu

The Options menu allows the access to the following commands:

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| View |  | Opens the View submenu |
| Freehand Drawing |  | List of commands that are used to draw or write texts on the window. See [here](../../../Toolbars/ToolbarFreeHand.md) for a complete description of the commands. |
| Properties | E | Opens the interface to configure the window. |
  
#### 

#### View submenu

Shows the pop-up sub menu to select the graphic elements of the window that can be shown or hidden. The displayed elements are highlighted with a check mark on the left. Show All & Hide All show and hide all elements respectively.

Left Scale Y: shows or hide the vertical scale.

Cursor Values: shows or hides the box with channels name end value at the top of the window.

X Scale: shows or hides the X Scale.

Orthogonal Scale: shows or hides the values of X and Y axes when scale layout is Inside.

#### Toolbar

The toolbar allows the access to the following commands:

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Load |  | Opens a window to select a configuration file corresponding to a G-G Diagram window. |
| Save |  | Saves the actual window configuration on a file. |
| Properties | E | See the description of the command in the Options Table. |
| View |  | See the description of the command in the Options Table. |
| Show/Hide All Scales Y |  | Shows / Hides the Y scales in all windows that display them. |
  
#### 

#### Pop-up menu

By clicking with the right button of the mouse on the graphic area of the window, on the information box or on the scales, the following pop-up menu is displayed:

This section will describe only the commands that have not already been described previously.

| COMMAND | DESCRIPTION |
| --- | --- |
| Print Window to Clipboard | Copy the image of the window in the current state on the clipboard. |
| Window | Opens the [Window submenu](../../../Menu/MenuWindow.md#MenuWindow_submenu) |
| Datasets | Displays the list of the available Datasets and allows choosing the Dataset to be enabled. |
  
#### Keyboard Shortcut

To see the complete list of shortcuts available for the graph window, click [here](../../../Shortcut/WindowsShortcuts.md#ShortcutGG). Below are listed those shortcuts that do not appear in any of the commands and of the toolbar buttons described before. These commands can be executed only from keyboard. 

| SHORTCUT | DESCRIPTION |
| --- | --- |
| + | Zoom In |
| - | Zoom Out |
