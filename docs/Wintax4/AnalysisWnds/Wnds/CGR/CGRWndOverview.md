### Gauge Window Overview

The Gauge window thanks to an automotive instrument appearance displays the value of the sampled channels when acquired in real time or at the current position of the cursor in post processing analysis.

If more than two laps are loaded for comparison, the Gauge Window will analyze the first two enabled datasets.
