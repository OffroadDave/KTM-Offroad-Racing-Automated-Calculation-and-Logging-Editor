### Diagnostics Report Window Overview

The Diagnostics Report window saves the changes of status on the rise front, from a low to a high value, of each bit of channels configured as Bitmap, that form the [diagnostic](../DGS/DGSWndOverview.md#DGS_FinestraDiagnostici_StrutturaDiagnostico) . Each change of status, event , is notified as a report.

The window can be used both for real time and post processing analysis.
