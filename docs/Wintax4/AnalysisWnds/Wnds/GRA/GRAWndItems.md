### Window Elements

The [Graph](GRAWndOverview.md) window is divided into regions containing graphic elements (scales, graphs, information boxes, areas).

####  Graphic area

The graphic area shows the graphs of the configured channels, the cursor of the X axis, the grid of the window and the grids of each channel, the transparent cursors (name and value compared to the position of the cursor), the divisions of the maps and the divisions of the finish lap.

The graphs are arranged on the basis of the layout mode: in Parallel they are parallel and not overlapping, in Overlay they share the whole vertical area and the overlap, in Manual they are vertically arranged as set by the user and can be overlapping.

In some licenses the graphics area can be divided into two, three or four smaller horizontal strips. The areas are separated by a divider with which you can resize them. Each area can be hidden, but at least one is always visible.

####  Zoom Bars

Horizontal Zoom Bar: displays the percentage of horizontal zoom in the window, allows moving of the horizontal zoom area.

Vertical Zoom Bar: displays the percentage of vertical zoom in the window, allows moving the vertical zoom area.

It is also possible to scroll the graph using the [mouse scrolling wheel.](../../../WTXSetup/WndGeneralSetup/WTXSetupGeneralSetup.md#Invert_mouse_Wheel_direction)

####  Y Scale

The Y Scale area shows the values scales of values of the configured channels.

The vertical arrangement of the Y scales changes according to the configured layout mode.

####  X Scale

The X Scale area shows the time or distances scales covered according to the set an X-Axis mode.

####  Value of the X Cursor

The X Cursor area displays the current value of the cursor for the X axis.

####  Channels Information

The Channels Information area shows inside text boxes the information of the configured channels; name of the channel, value in relations to the current position of the cursor, minimum and maximum value since the beginning of the lap (available only in real time mode). If the channels configured are most of the space available, you will see a scroll bar that can be moved up or down with the mouse pointer or [with the mouse wheel.](../../../WTXSetup/WndGeneralSetup/WTXSetupGeneralSetup.md#Invert_mouse_Wheel_direction)

The same information can be displayed also in the graphic area, on the top right in the rectangle dedicated to each channel (Transparent Cursor Values) or close to the cursor (Follow Graph Cursor).
