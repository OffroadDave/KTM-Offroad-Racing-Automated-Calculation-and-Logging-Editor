### Notes Configuration Window

The configuration window allows configuring the [Notes windows](NOTESWndOverview.md). The configuration window contains two pages: Options, Script.

Menu, toolbar and pop-up menu aid the user to configure and manage commands of window.

#### Options Page

The Options page allows configuring the graphical aspect of the window; it is composed by the section Window Options

##### Window Options

It allows configuring the graphical settings of the window. Each box can be edited by double clicking with the left button of the mouse or by pressing the shortcut Space Bar.

  * Custom Font: If checked the local font is used in the window; if unchecked the font configured in Setup, General, Default Appearance is used.

  * Font: Opens the [Font configuration page](../Common/Common.md#CommonConfFont). 

  * Text: Sets the text color.

  * Background: Sets the background color of the window.

  * Read only: Sets the read only property of the window.

  * Title: Field for writing the title. The maximum length is 50 characters.




#### Script Page

The Script page enables configuration of scripts linked to the events of the [Notes](NOTESWndOverview.md) window or of the application, in VBScript or JScript. See the [Windows Scripting](../../../Scripting/WindowsScripting.md) section.

#### Menu

The menu of the window allows the access to the following commands, divided by sub menus:

##### File Menu

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Apply | A | Applies the present setting of the window |
| Cancel |  | Closes the window without applying the present setting |
| Load |  | Opens a dialog window to select a configuration file to be loaded. |
| Save As |  | Opens a dialog window to select a configuration file (.not), to save the present setting |
  
##### View Menu

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Previous page | Ctrl \+ Shift + Tab | Enables the page of the window previous to the one currently in use |
| Next page | Ctrl \+ Tab | Enables the page of the window next to the one currently in use |
  
#####  Help Menu

| COMMAND | SHORTCUT | DESCRIPTION |
| --- | --- | --- |
| Help | F1 | Launches the WinTAX4 help, if available. |
  
## 

#### Toolbar

The toolbar enables the access to the following commands:

| COMMAND | DESCRIPTION |
| --- | --- |
| Keep Visible | Enables the Keep Visible mode ensuring to keep displayed the configuration window while other application windows are being used |
| Cancel | Closes the configuration window without applying the setting |
| Apply | Applies the present setting to the graphs window |
| Load | Similar to the Load command of the File menu |
| Save As | Similar to the Save As command of the File menu |
| Previous page | Similar to the Previous page command of the View menu |
| Next page | Similar to the Next page command of the View menu |
| Channel Browser | Displays the pop-up menu to select the page in the Channel Browser window. |
