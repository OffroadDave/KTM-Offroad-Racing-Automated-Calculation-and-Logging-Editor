### Notes Window Overview

Allows user to create a window used to write and display a note in text format. The text is editable directly from the window and is saved in the configuration. In configuration it is also possible to change the font and color of text and background.

On this window it is possible to perform cut, copy and paste operations; the text can be made read-only to protect it from unauthorized changes.
