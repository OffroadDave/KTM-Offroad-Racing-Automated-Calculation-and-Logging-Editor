### Window Elements

The window shows for each diagnostics an info box containing the name and the value of the possible selected channel followed by bits bar or by a text box for each channel forming the diagnostics.

The bits bar is displayed when the channel is of Bitmap type.

Each bar bit is formed by three lines:

  * a label indicating the bit index or the Bit Text (only with Vertical layout)

  * the current led indicating the current status of the bit

  * the history led indicating if the current led has switched at least once since the beginning of the acquisition, if the real time analysis is used, or since the beginning of the DataSet, if the post processing analysis is used.




The text box used for the Numeric type, shows the name of the channel and the current value.
