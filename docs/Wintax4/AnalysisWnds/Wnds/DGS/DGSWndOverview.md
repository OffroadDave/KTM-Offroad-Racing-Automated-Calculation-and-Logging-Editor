### Diagnostics Window Overview

The Diagnostics window shows the bits status of the channel as if its value was represented in binary format.

It can be useful to analyze the channels representing bits masks, and the change of status of each bit has a special meaning that can be interpreted independently from the other bits of the channel.

The window can be used both for real time and post processing analysis.

If more than two laps are loaded for comparison, the diagnostic window will always visualize analysis data for the main dataset.

###  Diagnostic Definition

A diagnostics is a container formed by 32 virtual bits that can be divided into maximum four channels.

Each diagnostics channel, DiagChannel, is a channel available in the table and can be represented as mapped bits or in numeric form (decimal or hexadecimal).
