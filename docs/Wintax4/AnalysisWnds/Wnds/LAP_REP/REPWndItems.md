### Elements of the window

This window is a table structured in three parts. The first one is the header, the middle one is the main table and the one at the bottom, in gray color is relative to statistics.

#### Header

In the first row of the header there are some Session information. This row can be hidden. The following two header rows contain the name of the channel and the calculated statistics. The small colored square identifies the color of the loaded Dataset.

#### 

#### Table

In the middle table each row identifies a lap or a part of a lap; the number of laps depends on how the table has been configured. There are five possible modes: four of them (Session, Run, Selected, Single Lap) will show laps and the other one (Section) will show one lap at a time, divided in sections. 

  * Session Mode: All laps of the current session; if the configuration lap filters are enabled, the number of laps might be lower.

  * Run Mode: All laps of the current run; if the configuration lap filters are enabled, the number of laps might be lower.

  * Selected Mode: Only the laps loaded in WinTAX4; if the configuration lap filters are enabled, the number of laps might be lower.

  * Single Mode: Only the first lap loaded in WinTAX4.

  * Section Mode: Only the first lap is loaded in WinTAX4, split in sections of the track.




#### Statistics

The Statistics area, which is visible in the lowest part of the "Lap Report" window, shows the statistics summary.
