### Elements of the window

####  Header

The header is composed by the first three rows of the table; this rows are visible even if there are no channels loaded; the row Time and the row Distance can be hidden with a configuration flag. 

In the first column there are label Channels; in each of the others columns there are a) a small colored square with an indication of the dataset b) the name of the dataset c) a small square button with a triangle icon which permits to show the differences between the datasets. 

The second and the third rows show the value of time and distance corresponding to the value of the channels in the Dataset.

####  Area of the Channel Values

The area of the channel values covers the rest of the window. Each row corresponds to a channel and its value. There are two fields for each channel: channel name and current value. In case there are more datasets loaded in comparison, there will be many numeric fields are datasets enabled.
