### Window Elements

####  Graphic Area

The graphic area displays the graphs, the cursor, the window and the grid of the window.

####  Y Scale

The Y Scale displays the scales of the configured channels. The Y Scale can be automatically or manually configured. The arrangement can be Parallel, Overlay or Manual.

####  X Scale

The X Scale displays the scale of the channel identified as X. The X scale can be automatically or manually configured and can be a custom channel or an internal lap counter (default). The value corresponding to the current position of the cursor is shown on the left; the name of the channel (or the internal lap counter) is shown on the right. 

####  Cursor Values

The Y channel information area displays the name of the channels, the statistic to be calculated for the channel. and the values corresponding to the present position of the cursor. It is on the right of the window.
