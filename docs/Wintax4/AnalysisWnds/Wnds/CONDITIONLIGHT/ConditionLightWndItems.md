### Window Elements

The "Condition Light" window is formed only by a text area which shows the configured messages calculated by conditions.

#### Information Area

This area displays the messages associated to the verified condition at the current position. The window manages one or more channels and works with single lap or with compare of laps. In the case of comparison a small colored square to the left side of the channel will be shown to identify the related lap. The window supports up to 11 datasets: (10 datasets + reference lap)

The window will be divided in several sections, accordingly to the number of configured and valid channels. The layout mode for channel distribution is Horizontal, Vertical and Automatic. In case of compared laps each section is split in two or more cells corresponding to the number of compared laps. If one or more channels are configured in setup page but are not available within the current loaded dataset, it will / they will not be displayed in the window.
