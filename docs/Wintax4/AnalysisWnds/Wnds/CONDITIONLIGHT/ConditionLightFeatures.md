#### Condition Light Window Overview

The Condition Light window displays a message set by the user that depends on the value assumed by a channel in relation to the configured conditions. The message is shown at the exact instant of the Real Time acquisition or at the current position of the cursor in the post processing analysis. The window works with single lap or with comparison of more laps and can manage one or more channels. The user has also the option to view the value assumed by the channel. 

The maximum number of allowed conditions is 16. The conditions are checked in sequence: if one is verified, the following ones are ignored; if it is not verified, the next condition will be examined. If all of the conditions are not verified, the window displays the text configured in Channel section.
