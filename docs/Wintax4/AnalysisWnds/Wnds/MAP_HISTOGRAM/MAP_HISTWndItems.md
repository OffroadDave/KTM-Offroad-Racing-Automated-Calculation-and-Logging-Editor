### Window Elements

####  Graphic Area

The graphic area displays the histogram of split times. On top of each histogram, the value in m:ss:mmm of the split time is displayed for each section. The color of the columns is the color configured for the first lap compared in the Setup / General. If it is a comparison, the column shows on the top of itself the split time difference value; the columns color will be inherited from the color assigned to the comparison laps. The columns colors are set according to which one of the two sections that are being compared is completed in the shortest time: the color of the laps which has the fastest split time is taken as reference.

####  Y Scale

The area of the Y Scale displays the scale indicating the time in seconds.

####  X Scale

The X Scale area displays the range scale in which the channel is divided. The number of columns corresponds to the quantity of sections configured in the map.
