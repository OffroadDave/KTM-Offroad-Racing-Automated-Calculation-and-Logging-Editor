### Map Histogram Window Overview

The "Map Histogram window" shows a histogram indicating the distribution of the split time according to map sections. This window has as many columns as the sections of the map. In single lap mode the height of each column is given by the value of the split time in the section. In the comparison mode, the first two laps are analyzed, no matter how many laps are compared and the height of a column is determined by the difference between the split times of the two laps in the same section.
