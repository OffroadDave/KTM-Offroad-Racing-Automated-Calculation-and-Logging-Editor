## Common Controls (for all Analysis Windows)

This section of the manual explains the common controls that are available on all analysis windows that allow the user to move, resize or reduce the size of the window.

Windows can be configured in two different modes: 

  * Captions enabled (default mode)

  * Captions disabled




##### Window with captions: 

| Window area | Description |
| --- | --- |
| Context icon | Double clicking on the icon, allows closing the window. (Clicking on the icon shows an extra menu with the standard function for the context menu) |
| Settings screen | Clicking on this icon, will open the settings screen for the active window. |
| Minimize | Will reduce the active window to minimized state |
| Maximize | Will increase the window size to use all available space. |
| Close Window | If clicked, the window is closed. |
  
##### Windows with no captions:

The user can maximize the available space by disabling the captions on the windows: (this can be achieved by clicking on "Windows -- Toggle captions".)

The move handle and resize handle appear only when the mouse hovers on the 2 specified areas.

Both the resize handles and movement handles are available on all 4 sides of the window: With regards to the resize handle, the top and bottom sides allow to increase and reduce the height of the window. The left and right sides instead allow to adjust the width of the window.

The move handle is used for moving the whole window in another area of the screen, within the limits of the application main screen.

Note: in No Caption Mode, it is also possible to quickly move a selected window only using the mouse and the keyboard by pressing on CTRL + ALT and then clicking and dragging the window (grabbing in the graph area) to the selected destination.

##### 

##### Hidden Controls in "No Caption" mode:

Hovering with the mouse on the 2 zone indicated by the arrows, will display extra controls for the window:

| Window area | Description |
| --- | --- |
| Context icon | Double clicking on the icon, allows closing the window. (Clicking on the icon shows an extra menu with the standard function for the context menu) |
| Minimize | Will reduce the active window to minimized state |
| Maximize | Will increase the window size to use all available space. |
| Close Window | If clicked, the window is closed. |
  
##### Resize from the corner

Hovering on each of the corners of the window allows also to display the corner handle, which allows both height and width of the window to be resized at the same time.

#### 

#### Settings:

In the settings screen (Setup -- General -- Default appearance) it is also possible to modify:

  * Colors of the caption background (caption mode)
  * Colors of the text (Caption mode)
  * Text height (Caption mode)
  * Color of the "Move area" (No Caption mode)
  * Color of the "Resize area" (No Caption mode)
  * Button style for the window (Both caption and No Caption mode)
