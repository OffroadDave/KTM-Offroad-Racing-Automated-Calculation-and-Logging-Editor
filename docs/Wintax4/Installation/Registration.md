## Registration

  1. Run WinTAX4.

  2. On the first run, a registration window will be presented requiring the user to insert a Registration ID and a password




The password is generated from the Registration ID by WinTAX4 Password Generator, a separate tool which is supplied with a protection dongle as part of the WinTAX4 licence. The protection dongle authorizes WinTAX4 Password Generator to create a fixed number of passwords

  3. Enter the generated password and press Start WinTAX4

  4. After the first successful start, WinTAX4 will not prompt again for a password.
