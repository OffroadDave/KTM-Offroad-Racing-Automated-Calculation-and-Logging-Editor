## Installation

IMPORTANT NOTE: The install procedure requires administrator rights. Make sure you have the correct permissions before performing the installation. If you have questions about this, ask your system administrator.

WinTax is distributed with 2 different installation types:

  * "[Admin User](WinTAX_Classic_InstallProcedure.md)" Installation:

    * It requires user to have Elevated privileges when executing the install procedure and during the execution of the program.

    * It can be installed multiple times in different folders. 

  * "[Standard user](WinTAX_STDUser_InstallProcedure.md)" Installation: (This version has some limitations / characteristics if compared to the "Admin User" version of WinTAX) 

    * Only the last installed instance of WinTAX can work correctly.

    * Data is always saved in the public document folder

    * The zip file that is delivered is tagged with the _STDUSER suffix to help distinguish the 2 distributions. (es. "Install_WTX_1.0.0.0-64bit_LicenseName_STDUSER.zip )




WinTAX is provided with password or dongle. The dongle just need to be inserted in the computer, while the password version needs to be registered before WinTAX can be used. [See here for more information](Registration.md)
