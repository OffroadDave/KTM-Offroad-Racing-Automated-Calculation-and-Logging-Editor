### Local Groups

In some licenses there is the possibility to configure Local Groups. With this feature you can organize channels in custom logical containers. For every group the user can define name, list of channels and shortcuts. The Local Groups are listed in [Channel Browser](../../WTXWorkWindows/WndChannelBrowser/Channel_Browser.md) as a new TAB. The Local Groups can be used in Graph windows, only for post processing mode. When the user adds a group in a Graph windows, all the channels of the group are automatically displayed. To add a group, simply drag the label from the [Channel Browser](../../WTXWorkWindows/WndChannelBrowser/Channel_Browser.md) list or push the shortcut you defined before. In configuration Local Group appears as a new tab as shown in picture below; each element of the grid can be edited by double clicking with the mouse or by pressing the space bar.

  * Label: shows the name of the local group.

  * Channels: it is the list of the channels belonging to the group. In order to modify this list, drag channels from Channel Browser or open the Properties window on Local Group page




Option buttons allow to add, delete and move channels in the list.

  * Accelerator: allows configuring the shortcut to have a quick access to the Local Group




  1.      * Press new shortcut key: enables to configure a new shortcut to be associated with the Local Group; to assign a new shortcut, focus on the text box and enter the new hot key. If the new shortcut has already been assigned to some other command, an alert message appears below the text box when the OK button is pressed for confirmation:




To cancel a shortcut without adding new ones, just use the Delete key or the Backspace key. If more than one local group has the same shortcut, all channels belonging to those groups are loaded in the graph window using that shortcut (logical OR).
